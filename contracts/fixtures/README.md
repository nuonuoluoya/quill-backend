# 原创联调样本

两本独立测试书：A Quiet Morning 和 The Lantern Garden。每本 3 章、24 句，其中 23 句有独立 MP3；每章都有独立完整 MP3。第一章第 3 句刻意标记待复核，用于验证逐句不可播放与整章可播放的区别。

文本为本次开发编写的短篇日常场景，不复制现有小说正文。语音由本机 Windows 已安装的 Microsoft Zira English TTS 离线生成，再转为 MP3；它是合成语音，不是真人有声书或小说原始音轨。这些素材用于本地功能联调；正式部署前运营方仍需确认目标环境的内容和合成语音使用范围。

生成器：`backend/scripts/generate-samples.ts` 与 `speak.ps1`。重生成需要 Windows SAPI 和 FFmpeg；使用已经提交的 MP3 样本不需要这些工具。音频变更后必须更换 buildId，不能覆盖已导入的不可变构建。

两书故意复用 c01、c01-s0001 等章句 ID，以检验跨书隔离。异常包由后端测试在临时目录从这些夹具构造，不污染正常样本。
